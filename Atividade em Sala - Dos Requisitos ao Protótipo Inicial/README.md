# Protótipo - App de Vagas de Estacionamento (linha de comando)

Protótipo em Python que simula três requisitos do app de estacionamento do
campus, executado inteiramente pelo terminal.

**Requisitos cobertos** (ver `requisitos.md`): RF01 - consulta de vagas
disponíveis em tempo real; RF02 - consulta de quantidade de vagas; RF03 -
sinalização de vagas reservadas.

**Como executar:**
```
python3 main.py
```
